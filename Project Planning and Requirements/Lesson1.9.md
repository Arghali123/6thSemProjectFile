# Lesson 1.9 — Use Cases & User Stories

## 1. What is a use case?

A use case describes how a user interacts with our application to achieve a particular goal.

For example:

A student wants to log in to our platform.

The use case describes:

* Who performs the action?

* What does the user want to achieve?

* What steps does the system perform?

* What happens if something goes wrong?

### Simple example

## Use Case: Student Login

Actor

Student

Goal

Access account

Basic flow

1. Student opens the login page.

2. Student enters email and password.

3. System validates credentials.

4. System authenticates the student.

5. Student is redirected to the dashboard.

This is a use case.

## 2. What is an actor?

An actor is a person or external system that interacts with our application.

For our project:

Actors

Student

Uses career and skill development features

Admin

Manages platform information

External AI Service

Supports resume analysis, if an external AI provider is used

Payment Gateway

Processes premium-service payments

Note: The AI service and payment gateway are external actors only if we integrate external providers. They are not human user roles.

## 3. What is a user story?

A user story describes a feature from the user's point of view.

The common format is:

> As a \(user\), I want \(functionality\), so that \(benefit\).

### Example

User Story:

> As a student, I want to view my career compatibility score so that I can understand which career paths match my current skills.

Let's break it down:

| Part                                         | Meaning |
| -------------------------------------------- | ------- |
| As a student                                 | Who?    |
| I want to view my career compatibility score | What?   |
| So that I can understand suitable careers    | Why?    |

### Another example

> As an administrator, I want to manage career requirements so that users receive updated career information.

User stories help our team understand what to build and why.

# 4. Use Case vs User Story

| Use Case                    | User Story                      |
| --------------------------- | ------------------------------- |
| Describes interaction steps | Describes user need             |
| More detailed               | Short and simple                |
| Includes alternate flows    | Focuses on value                |
| Useful for system analysis  | Useful for development planning |

Example:

* User Story: Student wants to upload a resume for skill extraction.

* Use Case: Describes file selection, validation, upload, analysis, result review, and error handling.

We will use both in our project documentation.

# 7. Detailed Use Case Example

Let's create a formal use case for one of our project's main features.

# UC-08: View Career Matches

Core Use Case

Primary Actor: Student

Goal: Identify career paths compatible with the student's skills.

Preconditions:

* Student is logged in.

* Student has provided relevant skill information.

Main Flow:

1. Student opens the career matching page.

2. System retrieves the student's relevant skills.

3. System retrieves career requirements.

4. Matching algorithm compares skills.

5. System calculates compatibility scores.

6. System identifies matched and missing skills.

7. System displays ranked career results.

Alternative Flow:

* If the student has insufficient skill information, the system asks them to complete their profile or assessment.

* If no career meets the configured matching criteria, the system displays an appropriate message.

Postcondition:

Career matching results are displayed to the student.

This format is useful for explaining our project's main functionality during evaluation.

# 8. Proposal-ready User Stories

User Stories

## User Stories

The following user stories describe the expected interactions between users and the proposed AI Skill & Career Management Platform.

### Student / Job Seeker User Stories

1. As a student, I want to register and log in securely so that I can access my personal account.

2. As a student, I want to manage my profile and skills so that my career information remains updated.

3. As a student, I want to complete skill assessments so that I can evaluate my current knowledge and abilities.

4. As a student, I want to upload my resume for AI-assisted skill extraction so that I can organize my skills more efficiently.

5. As a student, I want to explore different career paths and their required skills so that I can understand available career opportunities.

6. As a student, I want to view career compatibility scores so that I can identify potentially suitable career paths.

7. As a student, I want to identify my skill gaps so that I can understand which skills require further development.

8. As a student, I want to receive personalized learning recommendations so that I can work toward my career goals.

9. As a student, I want to track my learning progress so that I can monitor my professional development.

10. As a student, I want to view my progress through a dashboard so that I can understand my development in one place.

11. As a student, I want to purchase selected premium services so that I can access additional platform features, where applicable.

### Administrator User Stories

12. As an administrator, I want to manage user accounts so that I can maintain the platform's user information.

13. As an administrator, I want to manage career paths and required skills so that career recommendations use maintained information.

14. As an administrator, I want to manage assessment questions so that users can complete relevant skill assessments.

15. As an administrator, I want to manage learning resources so that users receive relevant recommendations.

16. As an administrator, I want to manage premium services so that available paid features remain updated.

These user stories will guide the development of the platform's functional modules and help define acceptance criteria during implementation.
