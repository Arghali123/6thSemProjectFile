# Lesson 1.1 — Project Definition & Vision

## 1. What is project definition?

Before developing any software, we must understand:

* What are we building?

* Why are we building it?

* Who will use it?

* What problem does it solve?

* What makes it different from existing systems?

This is called project definition.

For example, imagine you and Niraj start coding immediately without deciding the project's scope.

You might build:

* A login page

* A student dashboard

* A skill CRUD system

But later discover that your system doesn't actually provide meaningful career recommendations.

Project definition prevents this problem.

## 2. Project Title

# AI Skill & Career Management Platform

An intelligent platform for skill assessment, career matching, skill-gap identification, and personalized learning recommendations.

## 3. Project Abstract

Here is our initial project abstract, written in a format suitable for your proposal.

Project Abstract

# Project Abstract

The AI Skill & Career Management Platform is a web-based application designed to assist students and job seekers in identifying their skills, exploring suitable career opportunities, and planning their professional development.

The platform provides features such as student profile management, skill assessment, career matching, skill-gap analysis, resume analysis, personalized learning recommendations, and progress tracking.

It integrates Artificial Intelligence and Machine Learning techniques to extract skills from resumes and support intelligent career recommendations. A custom career-matching algorithm evaluates the compatibility between a user's current skills and the requirements of different career paths.

The system also provides interactive dashboards for visualizing skill development, assessment performance, career compatibility, and learning progress. Premium services can be accessed through an integrated online payment gateway.

The application will be developed using React for the frontend, Spring Boot for the backend, and PostgreSQL for database management. Docker, cloud deployment, and CI/CD will be used to deploy and maintain the application.

The primary goal of the project is to provide students with a centralized, data-driven platform for understanding their current capabilities, identifying skill gaps, and making informed career-development decisions.

This is our initial draft. We'll refine it after defining the requirements.

## 4. Project Vision

Our vision is:

> To develop an intelligent, accessible, and personalized career-development platform that helps students understand their abilities, explore career opportunities, identify skill gaps, and follow structured learning paths.

In simpler words:

Our platform should help students answer three important questions:

What skills do I have?

Skill profiles and assessments

Which careers match my skills?

Career matching and compatibility analysis

What should I learn next?

Skill-gap analysis and personalized learning paths

## 7. What makes our project different?

Our platform is not intended to be merely a student-management system or a basic CRUD application.

Its central functionality is the connection between:

* Skill assessment

* Resume analysis

* Career matching

* Skill-gap calculation

* Learning recommendations

* Progress analytics

For originality, you and Niraj will design your own matching formula, recommendation rules, data model, and evaluation process. We'll also test whether the recommendations are reasonable rather than treating AI output as automatically correct.
