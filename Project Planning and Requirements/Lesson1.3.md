# Lesson 1.3 — Project Objectives

## 1. What are project objectives?

Project objectives describe what we want to achieve by developing our project.

Think of it this way:

* Problem Statement: What problem are we solving?

* Project Objectives: What specific results do we want to achieve?

### Simple example

Problem: Students struggle to identify their skill gaps.

Objective: Develop a system that compares users' existing skills with career requirements and identifies missing skills.

An objective should be clear, meaningful, and achievable within our semester project.

## 2. Types of objectives

For our project, we will define two types.

### A. General Objective

The overall purpose of the project.

### B. Specific Objectives

The individual goals that help us achieve the general objective.

For example:

GENERAL OBJECTIVE

To develop an AI-assisted platform for personalized skill assessment, career exploration, and professional development.

SPECIFIC OBJECTIVES

* User profile and skill management

* Skill assessment

* Career matching

* Skill-gap analysis

* Personalized learning recommendations

* AI-assisted resume analysis

* Progress visualization

## 3. General Objective — Proposal Ready

General Objective

### General Objective

The general objective of this project is to design and develop an AI Skill & Career Management Platform that assists students and job seekers in evaluating their skills, identifying suitable career opportunities, recognizing skill gaps, and receiving personalized learning recommendations to support their professional development.

## 4. Specific Objectives — Proposal Ready

The specific objectives of the proposed system are:

Specific Objectives

### Specific Objectives

1. To develop a user-friendly web application that allows users to create profiles and manage their skills, interests, and career preferences.

2. To implement a skill assessment module that evaluates users' knowledge and abilities through structured assessments.

3. To design and implement a career-matching algorithm that compares users' skills and interests with the requirements of different career paths.

4. To identify skill gaps by comparing users' current skills with the required skills of their selected or recommended career paths.

5. To integrate AI-assisted resume analysis for extracting relevant skills and supporting user profile development.

6. To provide personalized learning recommendations based on identified skill gaps and career goals.

7. To develop an interactive dashboard that visualizes skill development, assessment results, career compatibility, and learning progress.

8. To implement secure user authentication, role-based access, and appropriate data management using a relational database.

9. To integrate an online payment gateway for selected premium services, subject to project scope and provider availability.

10. To deploy the application using suitable cloud and containerization technologies and evaluate its functionality, usability, and performance.

## 6. How to make objectives academically strong

Good project objectives should be:

* Specific: Clearly state what we will implement.

* Measurable: Have results we can test or demonstrate.

* Achievable: Fit our semester timeline and team capacity.

* Relevant: Directly address the identified problems.

* Time-bound: Be achievable before final project submission.

Avoid vague objectives such as “To make a very advanced AI system.”

Prefer:

“To implement a career-matching algorithm that evaluates compatibility between user skills and predefined career requirements.”
